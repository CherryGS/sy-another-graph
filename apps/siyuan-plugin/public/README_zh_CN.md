# 一个思源图谱

从笔记、块或搜索结果出发，在 2D / 3D 图谱中探索它们之间的联系。

## 开始使用

需要桌面版思源 **3.8.3+**。启用插件后，点击顶栏图标或按 **Alt + Shift + G**。
也可以在文档标题、文档树或块的右键菜单中选择 **在图谱中查看**。

默认显示文档和引用。打开 **筛选**，调整范围、节点类型和关系，或保存为常用预设。

## 搜索建图

在原生搜索或 [HZ 简搜](https://github.com/Hug-Zephyr/HZ-syplugin-simple-search) 中完成搜索，
点击搜索页签或弹窗中的 **用全部结果建图**。

- 纳入所有分页的命中节点，并补齐直到顶层文档的祖先链；默认显示全部类型并开启包含关系。
- **洋红色外环**标记命中，节点颜色和标签文字保留原样。隐藏命中块由文档代表时，
  图例和节点详情会注明 **命中投影**。
- 搜索使用独立的 **临时** 预设。点击 **返回原配置**，恢复此前的预设和未保存修改。
  临时搜索仅保留在本次会话中，再次建图会替换它。

修改搜索条件后需重新建图；刷新图谱会更新原命中 ID 的数据。读取时按钮显示进度，再点一次可取消。

## 在图上探索

- **节点与路径**：点击查看节点和关系，Shift 点击多选，按跳数和方向查看邻域或最短路径。
- **查看来源**：预览或打开原始块，查看关系的实际端点和依据。
- **更多关系**：开启包含关系、数据库连接，或按文档标题、名称和别名发现文本提及。
- **调整布局**：切换 2D / 3D，调节布局与标签，让社区内节点聚合；2D 可显示社区背景范围。
- **导出**：将当前可见图谱下载为 JSON。

文本提及支持 **排除词组**：每行输入一个完整名称或词组，点击 **应用排除** 后生效，
更新或另存为预设即可保存。临时搜索图的规则独立；排除 `01` 不会排除 `101`，
也不会直接移除节点或块引用。

## 数据与限制

- 读取本地索引，不修改笔记或关系字段。外观偏好保存在当前浏览器；JSON 导出会生成临时文件。
- 读取问题在左下角提醒，点击 **查看详情** 可查看并复制诊断报告；**刷新图谱** 会重新读取工作空间。
- 支持关键字、查询语法、正则和可完整分页的只读 SQL 搜索；暂不支持语义搜索、加密笔记本搜索
  及无法可靠分页的 SQL。单次上限为 50 万个命中、1 万页、2 分钟，读取不完整时会明确提示。
- 已在 Windows 的思源 3.8.3、HZ 简搜 1.3.6 验证。大图流畅度取决于硬件、图结构和布局参数。
