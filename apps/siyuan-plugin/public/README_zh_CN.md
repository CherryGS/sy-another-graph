# 一个思源图谱

从一篇笔记、一个块，或一组搜索结果出发，看看它们之间有什么联系。

## 开始使用

启用插件后，点击顶栏的 **一个思源图谱**，或使用快捷键 **Alt + Shift + G**。
也可以在文档标题、文档树或块的右键菜单中选择 **在图谱中查看**，从指定内容开始探索。

默认显示文档和引用。打开 **筛选**，可以显示更多块类型，调整范围、包含关系、
数据库关系和文本提及。隐藏的普通块可以由所属文档代表，其来源关系仍保留证据。

## 把搜索结果变成图谱

1. 在思源的搜索页签或搜索弹窗中完成搜索。
2. 点击结果数量旁的 **用全部结果建图**。
3. 图谱会打开一个标有 **临时** 的搜索预设，包含所有分页中的命中块。

支持原生关键字、查询语法、正则和可完整分页的只读 SQL 搜索。
也支持 [HZ 简搜](https://github.com/Hug-Zephyr/HZ-syplugin-simple-search)：
沿用它转换后的查询和筛选条件，无需重复输入或手动复制结果。
按文档分组只影响搜索页的显示，不会把分组标题误当成命中节点。

临时图会从每个命中块沿父子关系上溯，补齐列表、标题、所属文档及目录中的上级文档，
直到笔记本下的顶层文档。范围由命中节点和这些祖先链组成，菜单会分别显示命中数和补入的上级节点数。
默认显示全部类型并开启包含关系，让上下文连起来；重置临时筛选也会恢复这套配置。
你可以继续筛选、选择节点、查看邻域和路径；这些操作都受当前范围约束。

命中节点带有醒目的**洋红色外环**，补入的上级节点没有命中色环。
2D / 3D 下的小节点也保留可见环宽，关闭标签后仍能辨认；节点颜色和标签文字沿用原样。
图例分别统计当前可见的直接命中、命中投影和上级节点。
悬浮提示、图内搜索结果和节点详情也会标明来源身份。隐藏命中块的类型后，
代表它的文档会标为**命中投影**，详情说明承载了几个隐藏命中块。
色环不会自动选中或固定节点。选中命中节点时，选中环与洋红色命中环同时保留。

在 **筛选** 中调整临时配置，或点击 **返回原配置**，即可恢复此前的预设和未保存修改。
临时搜索会保留在本次会话的菜单里，再次建图会替换它。临时范围不会覆盖已有预设，
不会保存到磁盘，也不会在重载插件后恢复。刷新图谱会更新节点数据，并重新计算原命中的祖先链；
修改搜索条件后，需要再次点击建图来更新命中范围。

读取时按钮显示进度，再点一次可取消。修改查询或开始另一次建图会取消旧任务。
如果分页不完整、结果总数变化或读取失败，会明确提示，不会把部分结果当成全部结果。
单次支持最多 50 万个命中、1 万页，读取时间上限为 2 分钟；达到限制时请缩小范围。

目前不支持语义搜索和加密笔记本搜索；无法可靠分页的复杂 SQL 也会提示失败。
搜索和图谱数据分别读取，若命中块在图谱索引中不可用，筛选入口会标出缺失数量，
展开后可看到示例 ID。接入基于思源 3.8.3 和 HZ 简搜 1.3.6，后续原生搜索界面变化
可能需要适配。

## 在图上探索

- **节点和邻域**：点击查看节点，Shift 点击增减选中节点，调整跳数和方向追踪关系。
- **查看来源**：点击关系查看实际端点和证据，打开原文或使用思源原生预览。
- **筛选预设**：保存常用筛选组合，切换、复制和重命名；修改后明确更新或另存。
- **文本提及**：按需从正文中的文档标题、名称和别名发现潜在连接，与明确引用区分展示。
- **数据库关系**：查看数据库、真实条目、绑定块和已存储的关联字段；相同值不会自动建边。
- **社区聚合**：调节聚合强度，让社区内节点更靠近，保留节点原有颜色语义；
  2D 下还可以打开社区背景范围。
- **外观和导出**：切换 2D / 3D，调整布局与标签，将当前可见图谱导出为 JSON。

## 数据与读取提示

图谱读取思源的本地索引，不修改笔记、引用或数据库字段。图谱资源随插件本地提供，
图谱数据留在当前思源地址。外观偏好保存在当前浏览器中；切换页签或关闭后重开图谱，
会保留本次会话的图谱状态。JSON 导出会生成一个临时文件，点击 **下载 JSON** 保存。

读取问题会通过左下角 toast 提醒。点击 **查看详情**，或稍后点击左下角的提示按钮，
可以查看受影响的对象、原因、影响与排查建议，并复制诊断报告。每类最多保留 20 条详情，
超出部分会标明省略。数据变化或读取失败后，可点击 **刷新图谱**。

需要桌面版思源 3.8.3 或以上版本，目前在 Windows 的思源 3.8.3 WebUI 验证。
大图的流畅程度取决于硬件、图结构和布局参数；“仅文档”减少显示规模，不缩减源数据读取范围。
