# 一个思源图谱 · 使用指南

从笔记、块或搜索结果出发，在 2D / 3D 图谱中探索它们之间的联系。

[功能概览](../apps/siyuan-plugin/public/README_zh_CN.md) · [English](user-guide.md)

## 开始使用

需要桌面版思源 **3.8.3+**。启用插件后，点击顶栏图标或按 **Alt + Shift + G**。
也可以在文档标题、文档树或块的右键菜单中选择 **在图谱中查看**。

运行环境需支持 WebAssembly 异常处理（EH）。若检测不通过，请更新思源或浏览器；
不支持 EH 的旧引擎无法打开图谱。

默认显示文档和引用。打开 **筛选**，调整范围、节点类型和关系，或保存为常用预设。

界面自动跟随思源语言，支持简体中文和英文；中文变体使用简体中文，其他语言回退到英文。
笔记标题、别名、排除词组及已有预设名称保留原文。

## 文档排除

筛选面板提供两组可同时使用的规则：

- **仅排除文档内容，保留子文档**：移除命中文档及其文内块，保留下级文档及它们的关系。适合隐藏日期分类文档。
- **排除整个子树**：移除命中文档／块及全部后代，包括子文档。适合排除归档目录。

每行输入一个文档／块 ID、标题文本或 `/正则/`。普通文本按文档标题包含匹配；正则使用 JavaScript 语法，
固定忽略大小写，匹配经过全半角、大小写和空白归一化的完整标题，不搜索正文或别名。
例如在第一组输入 `/^\d{4}-\d{2}$/`，可隐藏 `2026-09` 分类文档，同时保留它下面的文档；
在第二组输入 `归档`，可同时排除标题包含“归档”的整棵文档树。两组重叠时，子树排除仍然生效。
块 ID 在两组中均排除该块及其下级块。以 `/` 或 `\` 开头的普通标题文本需在行首再加一个 `\`。

输入停顿后显示两组草稿合并后的命中目标、受影响文档和文内块数量，重叠内容只计一次。
**查看详情**可查找、分页查看受影响的文档和块。预览覆盖已读取工作区，包含当前范围外内容，
不改变已应用的图；**应用排除**才更新计算图，移除这些来源及相关边，不会产生替代引用边或删除思源原文。
被排除的分类节点不再充当包含边或路径的中介。

两组合计最多 2,000 条规则，其中正则最多 128 条，每项最多 256 个字符。无效表达式会标出行号；
正则匹配在后台运行，超过 10 秒会停止。修改或清空规则后可重新应用。
更新或另存为预设可保存规则；临时搜索图独立使用。旧版 ID 排除自动显示在“排除整个子树”中，保持原有含义。

## 搜索建图

在原生搜索或 [HZ 简搜](https://github.com/Hug-Zephyr/HZ-syplugin-simple-search) 中完成搜索，
点击搜索页签或弹窗中的 **用全部结果建图**。

- 纳入所有分页的命中节点，并补齐直到顶层文档的祖先链；默认显示全部类型并开启包含关系。
- **洋红色外环**标记命中，节点颜色和标签文字保留原样。隐藏命中块由文档代表时，
  图例和节点详情会注明 **命中投影**。
- 搜索使用独立的 **临时** 预设。点击 **返回原配置**，恢复此前的预设和未保存修改。
  临时搜索仅保留在本次会话中，再次建图会替换它。

修改搜索条件后需重新建图；刷新图谱会更新原命中 ID 的数据。读取时按钮显示进度，再点一次可取消。

## 在图上探索

- **节点与路径**：点击查看节点和关系，Shift 点击多选，按跳数和方向查看邻域或最短路径。
- **查看来源**：预览或打开原始块，查看关系的实际端点和依据。
- **发现关联**：选择起点后，点击工具栏的 **发现关联**，查找具有共同引用依据的候选文档。
- **更多关系**：开启包含关系、数据库连接，或按文档标题、名称和别名发现文本提及。
- **调整布局**：切换 2D / 3D，调节布局与标签，让社区内节点聚合；2D 可显示社区背景范围。
- **导出**：将当前可见图谱下载为 JSON。

工具栏的 **层级** 布局以所有已选节点为等权起点，按距最近起点的最少跳数从左到右排列。
它使用当前范围、节点投影和已启用关系，并跟随 **双向 / 顺箭头 / 逆箭头**；每条关系计一跳。
邻域深度只影响高亮，不限制层级计算。不可达节点紧凑排列在右侧独立区域，节点详情显示跳数。
2D 中每层是一列，3D 中每层是一个平面。未选择起点时保留当前位置并提示选择。
改变起点、方向、范围或维度会重新排列；其间可以拖动节点，点击画布上的 **重新分层并适应画布** 恢复排列。
层级布局停用力导向运动，切回 **力导向** 即恢复原有参数和暂停设置；节点颜色、关系和选择不变。

**发现关联** 提供两种规则：

- **引用相同资料**：A 和 B 都引用 X，X 是这条发现结果的依据。
- **被共同引用**：X 同时引用 A 和 B，X 是这条发现结果的依据。

发现按当前图中可用的文档汇总显式引用。选中块时使用其可用的所属文档，无法归入文档的选择会跳过。
范围、排除和搜索边界依然生效；文档代表隐藏块时，也只使用范围内的引用。需在筛选中开启引用。
文本提及、包含和数据库连接不计入得分。

候选按引用集合的加权重合度排序：通用引用对象权重较低，重复引用不加分。
多个起点分别比较，以最佳重合度作为候选得分，同时保留每个匹配起点的依据。得分不代表语义相似概率。

点击候选可高亮支持引用，并展开两侧的实际连接、查看出处；点击旁边的 **加入已选** 才会改变选择。
清除关联高亮或关闭面板后恢复普通图谱高亮。最多列出前 100 个候选并显示总数；
每个起点最多展示 50 篇支持文档，画布最多高亮 2,000 条实际边，依据有截断时会提示。
单次最多 128 个起点文档，超过计算预算或 60 秒超时时会明确停止。

文本提及支持 **排除规则**：每行输入一个完整词组或 `/正则/`，点击 **应用排除** 后生效，
更新或另存为预设即可保存。临时搜索图的规则独立。例如：

```text
待办
/^\d{2}$/
/^\d{4}-\d{2}-\d{2}$/
```

普通词组按完整名称排除；正则使用 JavaScript 语法，不附加 flags，默认忽略大小写，
匹配经过全半角、大小写和空白归一化的标题、名称或单个别名。
用 `^`、`$` 限定完整名称；上例的两位数字规则不会排除 `101` 或 `Project 01`。
要按文字排除以 `/` 或 `\` 开头的名称，在行首再加一个 `\`；旧词组会自动以文字方式显示。
这些规则不会直接移除节点或块引用。

最多 2,000 个词组和 128 个正则，每项最多 256 个字符（正则不计两侧 `/`）。
无效正则会提示行号；使用正则构建词表超过 10 秒会停止后台任务，可简化规则后重新应用。

输入停顿后可预览匹配的名称数和原始节点数，点击 **查看详情** 打开支持查找和分页的弹窗，
查看匹配名称、所属文档、节点 ID 和匹配依据。预览包括已读取工作区中范围外的候选名称，
不会改变当前图，也不等于将被移除的边数。

筛选面板的 **检查节点或关系** 可解释指定 ID 被排除、投影到文档或仅隐藏显示的原因。
输入第二个 ID 还可分别查看原始端点与显示端点之间的直接关系。

## 数据与限制

- 读取本地索引，不修改笔记或关系字段。外观偏好保存在当前浏览器；JSON 导出会生成临时文件。
- 读取问题在左下角提醒，点击 **查看详情** 可查看并复制诊断报告；**刷新图谱** 会重新读取工作空间。
- 若索引中有重复块 ID，图谱保留一条完整记录并报告受影响的块。重复记录内容可能不同，
  可从诊断打开来源核对；调整邻域跳数不会修复源索引，索引更新后可重新读取。
- 支持关键字、查询语法、正则和可完整分页的只读 SQL 搜索；暂不支持语义搜索、加密笔记本搜索
  及无法可靠分页的 SQL。单次上限为 50 万个命中、1 万页、2 分钟，读取不完整时会明确提示。
- 已在 Windows 的思源 3.8.3、HZ 简搜 1.3.6 验证。大图流畅度取决于硬件、图结构和布局参数。
