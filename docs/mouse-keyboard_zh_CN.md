# 鼠标与键盘操作

[返回使用指南](user-guide_zh_CN.md)

本表涵盖「另一个图谱」的画布手势、快捷键和界面控件操作。思源编辑器本身的快捷键仍以思源设置为准。
鼠标操作默认使用左键；“空白处”指没有节点、标签或关系线的位置。

## 打开图谱

| 操作                                              | 结果                                               |
| ------------------------------------------------- | -------------------------------------------------- |
| `Alt + Shift + G`；macOS 为 `Option + Shift + G`  | 打开图谱。可在思源快捷键设置中修改此命令。         |
| 点击思源顶栏的插件图标                            | 打开图谱。                                         |
| 文档标题、文档树或块的右键菜单 → **在图谱中查看** | 以对应文档或块作为初始范围。                       |
| 思源搜索结果中的 **用全部结果建图**               | 用该次搜索结果建立临时图谱；读取中再次点击可取消。 |

## 节点、选择与详情

“已选节点”是邻域、层级布局等功能的起点，也会固定位置并显示常驻标签；“查看详情”仅切换正在检查的对象。

| 操作                             | 结果                                                                     |
| -------------------------------- | ------------------------------------------------------------------------ |
| 单击节点圆点或标签               | 普通选择状态下选中该节点并显示详情；多选状态下只切换详情，保留已选集合。 |
| `Shift + 单击` 节点或标签        | 加入／移出已选集合，进入多选状态。                                       |
| 双击节点或标签                   | 打开对应的思源来源；没有可打开来源的逻辑节点不会跳到无关文档。           |
| 右键节点圆点或标签 → **复制 ID** | 复制该节点的完整图谱 ID；文档／块节点使用思源 ID。右键不改变选择或详情。 |
| 悬停节点圆点或已选标签           | 查看节点类型、笔记本、路径等摘要。                                       |
| 单击关系线                       | 查看关系详情和实际端点，不把端点自动加入已选。                           |
| 单击空白处                       | 普通选择状态下清空选择和详情；多选状态下只关闭详情。                     |
| `Shift + 双击` 空白处            | 清空全部已选并退出多选状态，释放这些节点的固定位置。                     |
| 点击工具栏 **清空选择**          | 清空已选、详情和当前探索结果，退出多选状态。                             |
| 点击详情卡片的关闭按钮           | 关闭该详情，不清空已选集合。                                             |
| 右键空白处                       | 收起节点右键菜单，不显示节点操作。                                       |

用 `Shift` 进入多选状态后，即使只剩一个已选节点，普通单击也只切换详情。要恢复普通单选，可先点击 **清空选择**，或 `Shift + 双击` 空白处。

## 拖动、缩放与 2D / 3D

| 操作                                        | 2D                                       | 3D                                                   |
| ------------------------------------------- | ---------------------------------------- | ---------------------------------------------------- |
| 拖动节点圆点                                | 移动一个节点。                           | 在当前视角对应的平面中移动一个节点。                 |
| 从已选节点圆点或常驻标签开始 `Shift + 拖动` | 整体移动全部已选节点，保持相对位置。     | 在当前视角平面中整体移动全部已选节点，保持相对位置。 |
| 从未选节点或空白处开始 `Shift + 拖动`       | 不移动相机、不框选节点。                 | 不旋转或平移相机、不框选节点。                       |
| 拖动空白画布                                | 平移视图。                               | 旋转视角。                                           |
| 按住 `Space` 拖动画布                       | 平移视图；从圆点开始也不拖动该点。       | 平移相机；从圆点开始也不拖动该点。                   |
| 在画布上滚动滚轮                            | 放大／缩小。                             | 拉近／拉远。                                         |
| `Ctrl + 滚轮`，或设备支持的触控板捏合       | 缩放；`Ctrl + 滚轮` 使用更大的缩放步幅。 | 同左。                                               |
| 双击空白画布                                | 放大视图。                               | 拉近视图。                                           |
| 点击画布右下角 **适应画布**                 | 把当前图谱纳入视野。                     | 同左。                                               |
| 点击 **重新分层并适应画布**                 | 层级布局下恢复分层排列并适应画布。       | 同左。                                               |
| 点击暂停／继续按钮                          | 力导向布局下暂停／恢复运动。             | 同左。                                               |

双击空白处也会执行单击空白的选择规则。`Shift + 双击` 空白用于清空选择，不用于缩小视图。
群体拖动过程中相机保持不动，滚轮暂不缩放。已选节点在拖动结束后继续固定；清空选择后释放。
普通拖动请从**圆点**开始；常驻标签支持 `Shift + 拖动`，普通文字标签不是画布平移的起点。

## 图内搜索与来源预览

| 操作                                         | 结果                                              |
| -------------------------------------------- | ------------------------------------------------- |
| 在工具栏搜索框输入标题或 ID                  | 查找当前图中的节点，显示匹配列表。                |
| 单击结果                                     | 与单击图中节点相同。                              |
| `Shift + 单击` 结果                          | 加入／移出已选集合。                              |
| 双击结果                                     | 打开对应来源。                                    |
| 搜索框中按 `↓`                               | 有查询词时打开结果列表，并把焦点移到第一项。      |
| 结果列表内 `Tab` / `Shift + Tab`             | 向后／向前移动焦点；`Enter` 或 `Space` 激活结果。 |
| 结果列表中按 `Esc`                           | 关闭列表并返回搜索框，保留查询词。                |
| 点击搜索框的清除按钮                         | 清空查询词。                                      |
| 悬停节点详情标题、关系端点或带来源预览的条目 | 预览思源原文；按住鼠标拖动时不触发预览。          |
| 点击节点详情标题                             | 打开该节点的来源。                                |
| 点击节点详情中的关系条目                     | 查看关系详情；悬停该条目可预览原文。              |

图内搜索用于查找节点，不会把当前图谱自动裁成结果集。思源的原生搜索建图是独立的临时范围，详见[使用指南](user-guide_zh_CN.md#搜索建图)。

## 筛选栏与预设

| 操作                                       | 结果                                                                 |
| ------------------------------------------ | -------------------------------------------------------------------- |
| 点击工具栏 **筛选**                        | 打开预设菜单；点击预设名称应用，点击编辑图标进入左侧筛选栏。         |
| 点击左侧竖向分类                           | 打开对应设置：范围、文档排除、关系、文本提及、分组、节点显示。       |
| 再次点击当前分类，或点击 **收起筛选内容**  | 收起内容区，只保留分类条；草稿保留。                                 |
| 分类条中按 `↑` / `↓`，或 `Home` / `End`    | 移动分类按钮焦点；`Enter` / `Space` 打开或收起对应分类。             |
| 点击分类条顶部返回按钮                     | 回到预设菜单。                                                       |
| 点击分类条底部关闭按钮，或筛选栏内按 `Esc` | 关闭筛选栏并返回工具栏筛选按钮。若有上层弹窗或菜单，先关闭上层。     |
| 打开筛选栏后点击图谱                       | 仍可操作图谱，筛选栏保持打开。                                       |
| 在排除文本框按 `Enter`                     | 换行添加规则；不会提交或应用。                                       |
| 点击 **应用排除**                          | 把该编辑区的有效草稿应用到图谱。文档排除的两组规则同时应用。         |
| 点击 **更新预设**／**另存为预设**          | 保存已经应用的筛选和分组配置；尚未应用的排除或集合草稿不会自动保存。 |
| 点击集合标题                               | 展开／收起名称和匹配规则，保留输入草稿。                             |
| 拖动集合卡片手柄                           | 调整优先级，越靠上越优先；松手后更新归属。                           |
| 集合手柄上按 `↑`／`↓`                      | 把集合向上／向下移动一位，立即更新优先级。                           |
| 点击 **应用集合**                          | 应用该集合的名称与规则；更新预设后才持久保存。                       |
| 切换集合启用开关                           | 更新参与分组的集合，保持卡片位置；重叠节点按当前顺序重新分配。       |
| 命名弹窗中按 `Enter`                       | 提交保存；`Esc` 或取消退出。保存进行中暂不接受取消。                 |
| 在设置面板、列表或详情内滚动滚轮           | 滚动该区域，不缩放图谱。                                             |

分类上的圆点和内容标题旁的 **未应用** 表示有排除或集合草稿。切换分类或收起内容区都会保留草稿；**关闭整个筛选栏或返回预设菜单会放弃尚未应用的输入**。已应用但未保存的筛选和分组，仍由当前预设的 **已修改** 标记提示。

## 通用控件的键盘操作

以下操作需先让对应控件获得焦点。

| 控件               | 键盘操作                                                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 界面按钮、输入框   | `Tab` / `Shift + Tab` 向后／向前移动焦点。                                                                                              |
| 按钮               | `Enter` / `Space` 激活。                                                                                                                |
| 开关、复选框       | `Space` 切换。                                                                                                                          |
| 下拉选择框         | `Enter` / `Space` 打开，`↑` / `↓` 移动，`Enter` 选择，`Esc` 取消；`Home` / `End` 跳到首尾，输入文字可定位选项。                         |
| 右键菜单、其他菜单 | `↑` / `↓` 移动，`Home` / `End` 到首尾，`Enter` / `Space` 执行，`Esc` 关闭。                                                             |
| 横向模式按钮组     | `←` / `→` 移动焦点，再按 `Enter` / `Space` 激活。                                                                                       |
| 设置中的横向页签   | `←` / `→` 切换页签，`Home` / `End` 到首尾。                                                                                             |
| 数值滑块           | 方向键微调；`Shift + 方向键` 或 `Page Up` / `Page Down` 大步调整；`Home` / `End` 到最小／最大值。鼠标拖动松开后提交，键盘调整直接提交。 |
| 文本框             | 使用常规文本编辑快捷键；Windows/Linux 的 `Ctrl + A/C/X/V/Z` 对应 macOS 的 `Cmd + A/C/X/V/Z`。                                           |
| 弹窗、帮助浮层     | `Esc` 关闭最上层。表单、保存中状态及平台行为以当前控件提示为准。                                                                        |

除打开图谱的命令外，插件没有另外绑定全局的复制节点、刷新、删除或暂停快捷键。`Ctrl/Cmd + C` 仍用于文本复制；复制节点 ID 请使用节点右键菜单。
